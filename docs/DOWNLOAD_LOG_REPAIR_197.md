# 1.0.197 下载与日志修复

2026-09-27 手机日志证实：启动选到剧情 3300、JS 103，但各只剩一个快速返回元数据的源；传输失败后 no-mirror。玩家重试剧情时只收到旧 CDN 元数据，候选降到 3289。

## 本次行为
- 同进程按包保留已知最高完整身份，网络重试不遗忘它；同版本内容冲突仍报错。
- 首次线路失败后有界补查其他发布源，只并入相同版本、大小、MD5；不会把旧 CDN 字节混进新包。
- 每文件仍最多尝试五个不同源。别的文件触发的冷却不再封死本文件尚未试过的唯一候选，不重置全局健康状态，也不循环尝试已失败的源。
- 启动失败弹窗的“重试”沿用原临时包及断点；资源管理中的“重下”仍明确从头下载。
- 续传保留旧分段布局，但网络 worker 数取当前设置与剩余分段数的较小值。
- 共享日志 Provider 返回文件名与大小，分享和 chooser 都携带只读 URI 授权。下载页打包完成后重新选择存活 Activity，点击/启动/失败留日志。
- 大日志保留每份末尾最多 2 MiB（从完整行开始），不再只导出启动噪声；最多五份、总量上限仍保留。

## 验证
宿主真实生产类测试：旧版重现 3300→3289、末尾错误丢失；候选通过身份、晚到同版本源、并发、Provider/Intent/Activity 桩测试。另跑真实本地 HTTP Range 续传与换线、Java/DEX 编译。
宿主 Android 桩测试不代表手机分享面板实际打开。手机网络、文件转发和游戏效果仍由维护者验收。本次未操作玩家设备。
此修复不包含双人字幕公开整合、角色“谣”名称修订或标题音乐调查。
