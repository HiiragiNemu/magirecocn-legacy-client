# 下载页固定信息与按钮

- 横幅下紧接版本状态边框；版本区保持固定，仅下方贡献说明滚动。
- 文件权限与线路入口使用紧凑胶囊，仍调用原设置与线路菜单，不更改权限或下载路由。
- 停留／进入游戏的可点击状态行显示气泡，边框范围与实际点击范围一致；普通下载说明不带按钮边框。
- 字号、关闭态音乐与序章按钮增加半透明衬底，避免在明亮背景上看不清。此处只改控件外观，不修改任何播放器逻辑。
- 浅色主题底部署名使用黑字，白色衬底不透明度从约95%降至60%；夜间保留浅色字与较淡暗底。
