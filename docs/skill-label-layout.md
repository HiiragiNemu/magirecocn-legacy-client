# 原生字体恢复（1.0.186）

## 被用户实测否定的 1.0.185

185 增加的 `QbEffectAnimeSkillName::setTitleToBone` 框高补丁没有解决用户截图中的技能名和角色名裁切，已移除。国服某个调用点 768×34 的静态差异不等于此次回归的原因；不再据此给 Label 叠加框高、Y 偏移或全局补丁。

## 改大圆之前的真实基线

`b6b404e`（6095180 的父版本）中 `fontPathFix()` 的目标是 `fonts/mbm_20160902.ttf`，不是原始 `TTZhiHeiGB3-W4.ttf`。6095180 在 2026-09-13 01:38:58 +0800 把这个目标改成了 TTDaYuanGB3。

该父版本原生载体的内部家族名为 MagiReco CN Medium，9,070,328 字节，SHA-256 为 `51383ac04bf0835445a0de382c07e6467f43991c6a51cf13a4327cad51f58b03`。这次恢复这份精确字节，不重新制作 metrics，也不以字体名称相近的其他文件代替。

引擎既有的 MTF 与 mbm 请求在构建期都指向该历史载体；效果与此前 MTF→mbm 的目标选择相同，免去重新引入字符串改写、场景白名单、FontAtlas/FreeType 拦截。字体、字号、尺寸和对齐参数仍原样交回原引擎。原生 mbm 和 WebView 的 mbm 字体族不是同一个载体。

## 保留而不回退

- TTZhiHeiGB3-W4 / TTDaYuanGB3 的 2026-09-19 reviewed 补字版保持逐字节不变。
- 历史原生载体已经含有上述补字所用的全部 49 个码位，包括 ♪ 和 ♯；恢复它不撤销符号支持。
- Web 智黑/ADV 字体分工、下载断点与线路选择、背景、权限入口保持不变。
- 185 的下载页父行自适应高度与两个 48dp 点击区保留，只撤掉字体框高猜测。

## 验证

`tools/check-fonts.py` 同时校验两份历史原生别名、两份 reviewed 补字字体的完整内容身份及音乐符号，并检查额外场景/字体加载/框高钩子没有被恢复。双 ABI 编译和文件校验与用户实机显示验收分开记录。
