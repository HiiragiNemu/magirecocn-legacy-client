# 战斗技能浮字框高（1.0.185）

1.0.184 的用户实测仍出现“坚定意志[IV]”底部裁切。字体资源映射正确不等于原版中文布局已经还原。

## 对应原版调用点

`QbEffectAnimeSkillName::setTitleToBone` 创建技能浮字时：

| 项目 | 当前日服引擎基线 | 国服原版 |
| --- | --- | --- |
| 字号 | 28 | 28 |
| 文本框 | 768 × 28 | 768 × 34 |
| 字体请求 | fonts/MTF4a5kp.ttf | fonts/TTZhiHeiGB3-W4.ttf |
| 水平 / 垂直对齐 | CENTER / TOP | CENTER / TOP |

ARM64 当前调用为 `0xa463a8`，框高指令为 `0xa46384`；国服调用为 `0x908a78`，尺寸常量为 `0x908c6c`、`0x908c70`。这些地址只是调查证据，不用于运行时硬编码补丁。

## 修正范围

保留原函数构造、骨骼绑定及所有参数；取得其创建的 Label 后，通过引擎公开的 `Label::setDimensions` 恢复国服的 768 × 34。只挂这个技能浮字构造器，不钩全局尺寸设置，不依赖类名猜测字体，不改字号、位置、锚点、字体 metrics、Web CSS 或字体文件。

ARM32/64 的 `shared_ptr` 按值参数均按非平凡对象的隐式指针转发，不在补丁中构造或析构该对象。缺少尺寸设置符号时记录错误并保留原行为。

## 下载页按钮

Logo 保持 64dp；其父行改为按实际内容撑高。权限与线路两个入口分别保留至少 48dp 的点击高度，避免两行按钮被一个 64dp 高的父容器截断。

## 验证边界

`test-native-skill-label-box.py` 执行实际包装函数的主机单元测试；`check-download-ui-contract.py` 检查父行测量方式。另需通过两种架构构建、Java/Dex 构建及字体资源保留检查。上述结果不代替用户实机验收，尤其应复查技能浮字、线路按钮和字体放大时的布局。
