# 下载页显示与手动文件权限

- 下载进度条与容量文字使用同一本轮统计，排除「本轮未检查」的包，不延用上轮的最高百分比。
- 容量使用十进制 MB；速度使用 MB/s。1200 kbps = 150000 B/s = 0.15 MB/s。主下载链换算维持原有字节口径，调试面板也统一按 MB/s 显示。
- 每次打开登录下载页按设备当地时间选图：06:00–16:59 白天、17:00–18:59 黄昏、19:00–05:59 夜景。直接使用用户提供的三张原图。
- 夜景自动开启现有夜间配色，不再叠加背景压暗滤镜。夜景下中央底板的不透明度由 80% 降至约 27%；保留手动主题切换。
- Logo 右侧「文件权限」可手动打开 Android 11+ 的所有文件访问设置，并显示当前状态。较早版本使用存储权限请求或应用设置。启动或下载不会自动索取此额外权限。
- 此权限用于共享存储的特殊读写需求，不代表能访问其他应用的私有目录，也不替代剩余空间检查；正常资源下载继续使用现有应用目录。

自动测试：`tools/test-download-presentation.py`、`tools/enable-storage-access.py --self-test`。实际设备外观与权限设置由用户验证。
# 持续低速下载

- 分块、热更新单连接、基础包单连接三条下载路径：只要持续收到数据，低于速度建议值也继续写入，不再因低速抛异常换线。
- 低速提示不等待答复，不阻挡提示卡片以外的操作。「关闭」「继续下载」都只移除提示，保留原下载任务、连接和断点；每次应用启动最多显示一次。
- 现有完全无数据超时、HTTP 错误、空间不足、内容哈希校验、用户明确点「重下」仍各自处理。低速与真正失败不是同一个状态。
- Logo 右侧提供独立线路选择，不把单/多线程模式冒充线路。主引擎在下载作用域内响应选择，与清除进度重下分开；备用引擎在下一次连接采用偏好。

## 手动换线与关闭

- 线路来自当前已启用的配置；选中后只改下载偏好，不改变版本查询取最高版本的逻辑。
- 已验证基础包块跨镜像复用；动态包用完整 version + size + MD5 固定断点身份。镜像自己的 ETag 不同不等于版本不同。安装前仍执行完整内容校验；不同版本的断点不混用。
- 主引擎切换会先关旧写入口并保存断点，再让原文件任务连接新线路，不启动第二个写者。单连接同样保留固定身份的断点；拒绝 Range 的线路不截断已有数据。
- 没有完整内容身份的旧格式下载延后到文件结束再使用新线路。备用引擎本次传输保持不变，下次连接使用所选偏好。
- 真正失败后的弹窗有“关闭（暂不重试）”；关闭、60 秒未选择、界面已经退出均停止本轮重试，保留可用断点。晚到的按钮事件不把已关闭回答变成重试。
- 手动换线不会改变解压/提交阶段，也不会替代用户明确点击“重下”的从零重启。

验证：`tools/test-manual-route.py --classes .build/classes --classpath '.cache/deps/*'` 使用本地 HTTP 服务验证热更与基础包跨镜像续传、版本隔离、不同 ETag、拒绝 Range、关闭后晚到点击等路径。测试类放在独立目录，永不进入 APK dex。
