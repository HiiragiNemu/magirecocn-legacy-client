# 下载页显示与手动文件权限

- 下载进度条与容量文字使用同一本轮统计，排除「本轮未检查」的包，不延用上轮的最高百分比。
- 容量使用十进制 MB；速度使用 MB/s。1200 kbps = 150000 B/s = 0.15 MB/s。主下载链换算维持原有字节口径，调试面板也统一按 MB/s 显示。
- 每次打开登录下载页按设备当地时间选图：06:00–16:59 白天、17:00–18:59 黄昏、19:00–05:59 夜景。直接使用用户提供的三张原图。
- 夜景自动开启现有夜间配色，不再叠加背景压暗滤镜。夜景下中央底板的不透明度由 80% 降至约 27%；保留手动主题切换。
- Logo 右侧「文件权限」可手动打开 Android 11+ 的所有文件访问设置，并显示当前状态。较早版本使用存储权限请求或应用设置。启动或下载不会自动索取此额外权限。
- 此权限用于共享存储的特殊读写需求，不代表能访问其他应用的私有目录，也不替代剩余空间检查；正常资源下载继续使用现有应用目录。

自动测试：`tools/test-download-presentation.py`、`tools/enable-storage-access.py --self-test`。实际设备外观与权限设置由用户验证。
