# 下载页显示与手动文件权限

- 下载进度条与容量文字使用同一本轮统计，排除「本轮未检查」的包，不延用上轮的最高百分比。
- 容量使用十进制 MB；速度使用 MB/s。1200 kbps = 150000 B/s = 0.15 MB/s。主下载链换算维持原有字节口径，调试面板也统一按 MB/s 显示。
- 每次打开登录下载页按设备当地时间选图：06:00–16:59 白天、17:00–18:59 黄昏、19:00–05:59 夜景。直接使用用户提供的三张原图。
- 夜景自动开启现有夜间配色，不再叠加背景压暗滤镜。夜景下中央底板的不透明度由 80% 降至约 27%；保留手动主题切换。
- 文件权限实现仍在源码中，但当前发布通过 `ALL_FILES_ACCESS=false` 关闭；APK 不声明所有文件访问权限，也不生成入口按钮。Logo 右侧保留线路按钮。
- 正常资源下载继续使用现有应用私有目录，不因关闭共享存储权限而迁移或改变写入方式。

自动测试：`tools/test-download-presentation.py`、`tools/enable-storage-access.py --self-test`。实际设备外观与权限设置由用户验证。
# 持续低速下载

- 分块、热更新单连接、基础包单连接三条下载路径：只要持续收到数据，低于速度建议值也继续写入，不再因低速抛异常换线。
- 低速提示不等待答复，不阻挡提示卡片以外的操作。「关闭」「继续下载」都只移除提示，保留原下载任务、连接和断点；每次应用启动最多显示一次。
- 现有完全无数据超时、HTTP 错误、空间不足、内容哈希校验、用户明确点「重下」仍各自处理。低速与真正失败不是同一个状态。
- Logo 右侧提供独立线路选择，不把单/多线程模式冒充线路。主引擎在下载作用域内响应选择，与清除进度重下分开；备用引擎在下一次连接采用偏好。

## 手动换线与关闭

- 线路来自当前已启用的配置；选中后只改下载偏好，不改变版本查询取最高版本的逻辑。
- 已验证基础包块跨镜像复用；动态包用完整 version + size + MD5 固定断点身份。镜像自己的 ETag 不同不等于版本不同。安装前仍执行完整内容校验；不同版本的断点不混用。
- 主引擎切换会先关旧写入口并保存断点，再让原文件任务连接新线路，不启动第二个写者。单连接同样保留固定身份的断点；拒绝 Range 的线路不截断已有数据。
- 没有完整内容身份的旧格式下载延后到文件结束再使用新线路。备用引擎本次传输保持不变，下次连接使用所选偏好。
- 真正失败后的弹窗有“关闭（暂不重试）”；关闭、60 秒未选择、界面已经退出均停止本轮重试，保留可用断点。晚到的按钮事件不把已关闭回答变成重试。
- 手动换线不会改变解压/提交阶段，也不会替代用户明确点击“重下”的从零重启。

验证：`tools/test-manual-route.py --classes .build/classes --classpath '.cache/deps/*'` 使用本地 HTTP 服务验证热更与基础包跨镜像续传、版本隔离、不同 ETag、拒绝 Range、关闭后晚到点击等路径。测试类放在独立目录，永不进入 APK dex。

## 文件访问范围核对

新增所有文件访问声明和系统设置入口并未迁移资源目录，也未替换文件写入方式。资源仍写入应用私有 files，APK 更新缓存仍在私有 cache/apk-update；现有共享存储导入/日志导出入口另行沿用。正常下载不要求开启此权限。该权限是 Android 的广泛共享存储访问权限，用户可保持关闭；声明或开启后可能触发厂商风险提示，具体原因以手机提示为准。

手动线路中的 Cloudflare 中转与个人 GitHub 直连是不同传输路径，不是不同内容版本；名称调整不改线路地址、断点身份或校验规则。

## 当前发布关闭共享文件访问

构建显式执行 `tools/enable-storage-access.py --disable --self-test --tree <构建树>`：移除最终 Manifest 的 `MANAGE_EXTERNAL_STORAGE`，同时把 Java 构建常量设为 false。界面不创建权限按钮，权限状态查询与设置入口也不执行。此前已有的其他权限、离线导入及日志导出逻辑保持原状。

GitHub 保留 `CNStorageAccess`、界面入口和 `--enable` 构建实现，未来获准启用时才同时打开声明与按钮；当前公开构建没有启用选项。去掉这一项可消除这项权限暴露，但不承诺所有手机安全软件都不再提示。

## 1.0.188 分包线路

- 基础包优先 EdgeOne / ESA，仅不可用时自动使用 Cloudflare / GitHub；用户可手动选择。
- 热更先并行查询所有发布源，选择最高版本，仅该版本且 size / MD5 一致的源可用于该包下载；手动偏好也遵守该限制。
- 首装、热更和 aria2 使用同一份固定版本身份；旧版源不参与下载尝试。
- ZIP 名旁显示该槽位的实际线路，事务块内部换线同步更新，已装未下载的槽位单独标明。

### 第 16 包：累计补充层

- `cn_js_update.zip` 固定为 JS 102，`cn_js_delta.zip` 使用独立版本号。
- 新安装先完成原有 15 包，再下载并应用第 16 包；正常启动先完成台词/JS 更新，再处理补充包。
- 第 16 包只携带相对固定基包改过/新增过的产品文件，累计保留先前修改；跳过中间版本也能覆盖到最新。
- 同名文件回退到基包内容时仍随补充包下发，避免已更新用户留下旧修改。删除另加事务支持前不自动发布。
- 手动重下旧基础包或 JS 后，重新应用已验证的补充包缓存；原有 15 包完成标记继续有效。
- 首包仅替换 `madomagi/resource/image_native/scene/top/toppage_bg_020.png`，保留同名 plist 和全部字体。
