# 手机下载页修正

- 线路弹窗按当前窗口限制高度，说明和线路共用滚动区；关闭、继续下载固定在底部，按文字实际高度布局。关闭仍不暂停或重下。
- 顶栏统一垂直留白，移除左侧滚动条独有的底部占位；内容区跟随实际顶栏和底栏高度。版本状态紧接图片，不再插入分隔线。
- 底栏使用独立高对比底色，不改变夜景图片和中央面板的透明度。
- 线路显示统一包含维护者署名，每包保留实际连接标签；标签另占整行，不挤压文件名。候选优先级、版本过滤、续传身份保持不变。
- 下载页五个作品链接按精确域名放行；同平台其他站点和伪装链接仍受原有检查约束。
- 统计说明上方依次放置 MADE IN MAGIUS、CyberNova 的赞助链接，与顶部作品链接区分开。
- 本次发布恢复手动文件权限入口和对应声明；普通下载不依赖开启此项，不改变资源写入目录。移除此权限的已发布版本仍被手机提示风险，当前尚无证据定位或消除厂商的具体判定，因此此恢复不是“已解决风险告警”的声明。

验证：`tools/test-mobile-download-ui.py` 检查布局约束及底栏对比度；`PackageRoutingTest.java` 验证线路与署名；`SafeLinkTest.java` 验证已展示链接和反例。编译与上述检查不替代手机显示验收。
