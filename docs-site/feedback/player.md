# 普通玩家反馈指南

你不需要懂任何技术。把下面四件事说清楚，就是一份高质量的反馈。

## 四件事

1. **现象**：看到了什么？（日文残留 / 错字 / 闪退 / 卡住 / 下载不动）
2. **位置**：在哪一步发生的？（尽量具体：哪章哪话、哪个按钮、下载到百分之几）
3. **必现还是偶发**：每次都这样，还是偶尔一次？偶发的话大概几次一遇？
4. **设备与版本**：手机型号、Android 版本、游戏构建号（`1.0.xx`，见[下载页](/download#版本号说明)）。

## 怎么提

点下面对应模板，照着填就行，带 \* 的是必填：

- 🐞 [报 Bug](https://（本仓库）/issues/new?template=bug_report.yml)
- 🔤 [报误译 / 漏翻](https://（本仓库）/issues/new?template=translation.yml)
- 💬 [体验与建议](https://（本仓库）/issues/new?template=feedback.yml)

## 截图怎么截才有用

- **误译/漏翻**：把整句截全，别只截局部——上下文决定该归哪一层修。
- **卡死/黑屏**：截卡住的画面 + 尽量记下**卡之前最后一步操作**。
- **下载问题**：把下载浮层整个截下来，上面每个文件的进度都在，一眼能看出卡在哪条线路上。

## 关于翻译的特别说明

- 看到**日文**：先分清是「字是日文」还是「字是中文但长得像日文字体」——
  后者是字体问题，截图里看得出来的话请顺手注明。
- 翻译以**通顺**优先，不逐字直译；觉得某句不通顺，直接写你觉得该怎么改。
- 名词（人名、地名、技能名）以中文 Wiki 为准，你认为某个名词翻错了，
  最好附上 Wiki 里的写法。

## 提完以后

Issue 会有回复，可能被追问更多信息——有空回一下就行。
修复通常通过**热更新**下发，不用重装 APK；重启游戏让它检查更新即可。
