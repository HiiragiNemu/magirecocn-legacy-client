# 更新日志

客户端版本以 CI 构建号命名（`1.0.<构建号>`）。构建号单调递增，
每次构建都能回溯到具体一次 CI 运行。

👉 **[下载最新版](/download)**（直链固定指向最新，不用挑版本）

## 两类更新，两种速度

| 更新类型 | 怎么拿到 | 要重装 APK 吗 |
|---|---|---|
| **热更新**（翻译、前端文本、引擎文本表） | 启动游戏自动检查，或重启触发 | 不用 |
| **客户端更新**（补丁层 bug 修复、新功能） | 下载新 APK 覆盖安装 | 要 |

绝大多数翻译修正走热更新——报错后通常当天就能通过热更下发。

## 最近的关键变化

（截至 `1.0.164`）

- **开机看门狗**：前端迟迟不出来自动重载一次页面；成功判据改看连续可见，别被开机瞬间骗过去
- **本地状态覆盖层**：服务端无状态，编队等本地状态改存客户端，重开不掉
- **崩溃记录增强**：开机记录进程是怎么死的（系统退出记录，与 logcat 独立）；logcat 双路收原生崩溃墓碑
- **下载浮层改版**：重下与停留放回下载浮层，顶栏一颗胶囊不动
- **调试悬浮窗**：改挂 decorView，不再依赖「悬浮窗权限」
- **TLS 探针**：服务端与客户端都在手机里时，也能一键查引擎连不连得上本地服务端
- **一批下载 / 热更 / 引导修复**（断点续传、热更事务恢复、看门狗超时等）

更早的：

- **1.0.84+** i18n 前缀匹配与热重载指纹修复
- **1.0.83+** armeabi-v7a（32 位设备）native string 布局兼容
- **1.0.82+** 序章分段调试开关（测试用）
- **1.0.80+** 序章流程修复（序章末尾自动重启、CONNECT 教学战斗卡死）
