# 常见问题（FAQ）

## 下载与安装

### 首次下载很慢 / 卡住不动？

客户端有多线路自动切换：某个镜像不可用或速度过低时会自动换线。
长时间停在同一文件上不动，请把下载浮层整个截图（左上角 LOG 胶囊里有
换线记录），按[进阶指南](/feedback/advanced)附上 `log/` 目录提 issue。

### 提示「应用未安装」或覆盖安装失败？

签名不一致。备份好**引继码**后卸载旧版再装。详见[下载页](/download#安装)。

### 每次启动都要重新下热更新？

不是正常现象。热更应用是事务化的，中断后会按 journal 恢复；
反复重下说明应用阶段在失败，请带 `log/` 目录报 bug。

## 翻译相关

### 为什么有的中文看起来像日文字体？

那是**字体**问题不是翻译问题：文本已替换，但渲染走的仍是日文字形路径。
已知在部分原生弹窗上出现。截图时报 issue 请注明「中文但日文字形」，
和「纯日文残留」是两条不同的修复链路。

### 剧情/战斗里还有日文？

分两种情况：引擎硬编码串（弹窗、战斗台词）补
`engine_i18n.tsv` 热更即可修；烘焙进图片的文字只能改图。
按[普通玩家指南](/feedback/player#截图怎么截才有用)截图报上来即可。

### 翻译质量如何？

以中文 Wiki 名词为准 + 通顺优先。发现误译请用
[误译模板](https://github.com/MagirecoCN-Revival-Project/legacy-client/issues/new?template=translation.yml) 提交，
热更下发修正，不用重装。

## 崩溃与兼容

### 打开就闪退 / 黑屏？

先确认：

1. 是不是覆盖安装后第一次启动——试试彻底清掉应用数据重装（先备份引继码）。
2. 设备架构：arm64 为主力支持；32 位（armeabi-v7a）设备请特别注明。
3. 仍然不行的，**务必带 logcat** 报 bug（[抓取方法](/feedback/advanced)），
   没有堆栈的闪退报告无法定位。

### 支持模拟器吗？

未做专门适配，能用与否取决于模拟器的 ARM 翻译层。欢迎反馈具体表现。

## 其他

### 数据安全吗？会封号吗？

补丁只改本地 UI、下载与文本渲染，不改与服务器的协议内容。
但使用任何第三方修改客户端都有固有风险，请自行权衡；务必**保管好引继码**。
